# 66将棋GUI

66将棋をGUI上でプレイし、66将棋AIをエンジンとして接続して対局できるデスクトップアプリです。  
人間同士の対局に加えて、人 vs AI、AI vs AI の対局を行えることを目標としています。

本プロジェクトは既存の将棋GUIとの互換性を目的とせず、66将棋専用の新規GUIとして開発します。  
AIエンジンとの通信には USI を利用します。

---

## プロジェクトの目的

このプロジェクトの目的は、以下を実現することです。

- 66将棋をGUIで遊べるようにする
- 66将棋AIをエンジンとして接続できるようにする
- 人 vs AI の対局を可能にする
- AI vs AI の自動対戦を可能にする
- 66将棋AIの開発・検証をしやすくする

---

## 役割分担
フロントエンド寄り
- gui
- controller
バックエンド寄り
- core
- engine

## 開発方針

- GUIは新規実装する
- 既存の将棋GUIのコードは参考程度に留める
- 既存GUIとの互換性は必須としない
- AIエンジンとは USI で通信する
- 画面表示とルール処理、エンジン通信を分離して実装する
- まずは見た目よりも動作を優先する

---

- 棋譜の簡易表示

- 人 vs AI の対局
- AI vs AI の対局

### 後回しにする機能
- 見た目の細かい調整
- アニメーション
- 高度な設定画面
- 長時間の連続自動対戦
- 複数エンジンの詳細管理

## ディレクトリ構成

```text
.
│  .gitignore
│  README.md
│  requirements.txt : このプロジェクトで必要なPythonライブラリを管理する
|  main.py : アプリの起動エントリポイント
│
├─controller : 対局進行やGUIと内部処理の橋渡しを管理する
│      game_controller.py : 1局の進行を管理し、GUI入力に応じて局面更新や手番切り替えを行う
│      match_controller.py : 対局モードやプレイヤー設定を管理し、対局全体の進行を制御する
│
├─core : 66将棋の局面やルールなど中核処理を管理する
│      move.py : 指し手や配置の情報を表現し、移動元・移動先・駒種などを扱う
│      position.py : 盤面、手番、持ち駒など現在の局面情報を管理する
│      rules.py: 合法手判定、指し手適用、終局判定など66将棋のルール処理を行う
│
├─engine : AIエンジンとのUSI通信を管理する
│      usi_parser.py : USIで送受信するコマンドや応答を解析し、扱いやすい形に変換する
│      usi_process.py : AIエンジンの起動・停止やUSIコマンドの送受信を管理する
│
└─gui : 画面表示とユーザー操作を管理する
       board_widget.py : 盤面と駒を表示し、クリックによる指し手入力を受け付ける
       main_window.py : アプリ全体のメインウィンドウを管理し、各GUI部品を配置する
       move_list_widget.py : 棋譜や指し手の一覧を表示する
       setting_dialog.py : 対局モードやエンジン設定などの各種設定画面を管理する
